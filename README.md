# 🌊 Flood Segmentation using U-Net vs ResNet U-Net Encoder

## 📌 Overview
This project performs **semantic segmentation** to identify flooded areas from satellite imagery using deep learning models.

## 🚀 Live Demo
[![Streamlit App](https://img.shields.io/badge/Streamlit-Live%20Demo-red?logo=streamlit)](https://floodsegmentation-j6zmnnfzwrtfd9ceutkln8.streamlit.app/)

## 🧠 Model Architecture
- U-Net
- ResNet-based U-Net Encoder
- Dice Loss & IoU Metrics

## 🗂 Dataset
- Satellite flood imagery
- Preprocessing:
  - Resizing
  - Normalization
  - Augmentation

## ⚙️ Tech Stack
- Python
- TensorFlow / Keras
- Streamlit
- OpenCV
- NumPy
